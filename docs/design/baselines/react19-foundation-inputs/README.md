# Preserved source inputs before F/2 repairs

This is the imported WebUI snapshot immediately before the current
`agentic-ui-frontend/frontend-react19-foundation/2` compatibility repairs. It
already contains the prior React migration, Promethity tokens and partial
agentic work. It is not an untouched upstream incumbent, a token-only rendered
variant, an accepted golden or evidence of visual parity.

`inputs.tar.gz` contains 1,004 source/configuration/locale/font/notice inputs.
`manifest.json` records every SHA-256 and the archive SHA-256. The source archive
is fixed; later work must add another snapshot instead of replacing its bytes.
There are no installed dependencies, build outputs, environment files, operator
data or credentials. Font bytes are local inputs under `src/promethity/fonts`.

`base-head-git-tree.json` records the immutable base commit/tree and Git object
IDs for the archived paths present at that revision, plus imported paths absent
at the base. Together with the archive hashes this preserves the difference
between committed incumbent inputs and the already modified import. Neither
source is automatically the approved visual reference; select and label the
actual incumbent and token-only reconstruction at the completed phase boundary.

The manifest lists the imported Promethity token/font/theme overlay source.
Use an isolated temporary reconstruction for later comparisons; never replace
the working application or alter this archive to make a comparison pass.
Render light/dark Files, Pins and Explore with matching real fixture content,
viewport, locale and route only after the full production phase completes.
No source hash or archive substitutes for those captures and operation checks.
