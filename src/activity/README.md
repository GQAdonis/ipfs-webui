# Current-identity decision observations

I/1 owns readonly authenticated data and domain hooks. `DecisionFeedProvider` is mounted once outside the shell in App; it shares the existing connection store. `DecisionProjectionScope` keys only its decision-domain children by local generation/server epoch, so ordinary route and chat owners remain mounted. Use `useDecisionFeed` for lifecycle/completeness/retention and `useDecisionIds`, `useDecisionObservation`, `useDecisionRows` only inside that explicit graph scope. A missing provider throws instead of accessing the entity library's default graph.

`createDecisionFeed({connectionStore,enabled,makeClient?,now?,schedule?,cancelScheduled?})` is side-effect free until `start()`. `start` returns `stop`; `stop` is resumable for React effect replay, while `dispose` is final. `setEnabled(false)` synchronously aborts and clears projections. One stream subscribes before its first snapshot marker triggers any list fetch. Snapshot/detail readers are bounded, generation/epoch fenced and readonly. `refresh()` never replays a write; it respects a current 429 hold. Known expiry/sign-out is owned by the shared connection store; a decisions 401 alone also covers missing OIDC route permission and cannot expire a console sign-in.

Snapshot fields are `generation`, `epoch?`, `scopeKey`, `graph`, `status`, `fresh`, `complete`, `hasMore`, `truncated`, `historyUnavailable`, optional `revision`, `historyStartedAt`, `retention`, and safe `error:{kind,status?,retryAt?}`. `hasMore` reports the server page flag; `truncated` also reports the local four-page/400-row/4MiB projection bound. Graph list `total` is always null. A partial or stale observed list is never a full current-identity count. Server retention remains globally 200 resolved/seven days, independent of this local projection limit. Epoch changes disclose history loss, not operation failure.

Changed/SnapshotRequired SSE frames invalidate only. Revisions are compared for equality only. Reconnect/overflow gets a new authenticated snapshot; cursor 400/409 resets pagination once and surfaces a failed fresh first page. Every nonpending/outcome record requires protected detail before entering the graph. Missing details are unavailable history, do not synthesize failure, and keep completeness/freshness conservative. Old optional receipts are replaced, never shallow-merged back into a later observation.

`getValidated(id)` and `readDecision(id,{signal?})` return only `{generation,serverEpoch,observation}` from private validated transport ingress, never authorization. Graph mutations/copied card observations cannot create that provenance. `readDecision` uses at most four distinct concurrent manual reads, clears/removes only within its matching current scope and cancels on retirement. I/2's trusted host adapter may combine current authenticated detail and current connection capture with canonical capabilities using the existing reviewed continuation; a card, entity row, label or locator alone cannot grant it. I/1 adds no resolver, CRUD, optimistic state, persistence, offline replay or backend fields.

Actual execution/presentation, HTTP/browser behavior, exact package resolution and subject-isolation acceptance remain unverified until the final production boundary. Authored tests have not run. Shared/UI/chat producers must run first so the standard built-package aliases resolve current source.

I/2's `DecisionWorkspace` supplies Home and Activity as explicit decision projection scopes while the existing PraxisWorkspace keeps the sole conversation/controller. Activity groups only actual `activity_id` values and reveals additional loaded rows without inventing a total. The shared card vocabulary presents all eleven decision states; read-only rows contain no answer callbacks. The native shared detail dialog requires a protected read before it can offer current owned-chat capabilities, and unsupported native dialogs fail closed.

`createInboxDecisionAdapter({feed,connectionStore,now?})` owns only one selected review and readonly detail operation, never a transcript or transport. `start()->stop`, `stop()` and `dispose()` control its subscriptions; `open(id)`, `close()`, `getContext(id)`, `getSnapshot()`, `subscribe()` and `sessionFor(controller)` are the host presentation seam. Its frozen `callbacks` are passed to the existing controller at creation. `getDecisionContext(id)` checks private fresh ingress against the current capture/generation/epoch and canonical owned-chat actions, expiry, shared native restrictions and exact reviewed operation. Authority kind is display attribution, not permission. Context remains outside the graph/card state. Every answer rereads protected detail before the existing typed continuation; the controller rechecks the current callback before its one actual transport lease. The shared approval arm and real activation checks are presentation guards, never resolver authority. No automatic write retry occurs and a local submission reports no approval or receipt.

`readDecisionResult(id,{signal?})` adds a discriminated protected-read result: `{kind:'observation',ingress}`, `{kind:'missing',generation,serverEpoch,decisionId}`, `{kind:'stale'}`, `{kind:'busy'}` or `{kind:'error',reason}`. Only an actual matching current detail404 yields missing. Revision changes, generation/epoch retirement, failed authentication/network reads, abort and capacity do not imply eviction or resubmission. Existing `readDecision` remains compatible and returns ingress or undefined. Fresh reads and callbacks never mark console expiry.

I/3 wires the browser-local `presentation-policy` into ownership. DecisionFeedProvider accepts optional presentationPolicy, combines its decisions boolean with the explicit enabled prop, and subscribes synchronously. Off stops the feed (including its connection subscription), cancels requests and clears maps. DecisionWorkspace independently stops its review adapter and unmounts decision-domain views, retaining an off/settings explanation. Ordinary route and chat owners stay mounted. Enabling captures the current connection rather than reviving the old scope.
