implementing F1.10. The only runnable boundary entry is
`COREPACK_ENABLE_AUTO_PIN=0 npm run test:agentic-boundary`, after the lead opens
the final packet. It derives the current local artifact once after the packet's
ordinary Vite build, records exact producer commands, then uses actual isolated
Kubo RPC and gateway paths. It never launches a dev server for acceptance.

enter the shipped source or artifact. No shared-tree checkout/reset/stash occurs.

The runner records actual current Node executable/version/hash (including any

exact commands, exit/output hashes, screenshots and RPC state. Linux/Windows or
unavailable native hardware are not inferred from macOS receipts. Independent
review and the complete outer boundary packet remain separate requirements.

### Explicit canonical make build receipts

`config.makeBuildReceipt` is an optional **test-only** path forwarded to the owned-node helper. Leave it absent to retain the original `go version -m` Makefile injection check. Go builds with `-trimpath` can omit the `-ldflags` metadata; explicitly supply a same-checkout `same-checkout-make-build-artifact-binding` v1 receipt below the Kubo checkout's `evidence/` directory for those builds.

The binding links immutable `originalReceipt` and `identityDiagnostic` files by relative path and SHA-256. Validation requires complete matching before/after/current source, module, Makefile and embed snapshots (including initial documentation, the full contract, app views, UI catalog and native confirmation Swift); current complete Go/Make inventory and HEAD; exact successful canonical `make build` argv/cwd/PID/time bounds and hashed public stdout/stderr; all three canonical linker injections; and matching current binary bytes, build info, version and Go toolchain. Missing, changed, unsupported or symlinked inputs remain blocked. A generic `PASS` field supplies no authority; historical blocked metadata results remain intact.

The receipt proves local build identity only. It supplies no backend compatibility, external collaborator delivery, BE-04 or lease authority. This test option does not run a build or bypass normal export/assembly validation. `KUBO_MAKE_BUILD_REGRESSION=<actual-kubo-checkout> npm run test:unit -- test/boundary/make-build-receipt.test.js` exercises the original owned-binary helper against the retained issue #11 owner build and actual source/binary files; ordinary portable negative tests use explicitly synthetic file fixtures.

Each non-test `go:embed` directive is checked against the captured byte inventory; a new uncovered embed target or unsupported directive syntax blocks. The corrected proof requires the genuinely fresh `node-delivery-v2` before/build/after capture. The earlier incomplete `node-delivery` proof remains historical and is rejected by the updated validator.
